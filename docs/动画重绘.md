# cuteQ 0.2 动作重绘与验收

本次覆盖全部现有动作：38 个行为名称，以及左右转身的 2 个过渡片段，共 40 个播放片段。待机、吃饭、招呼、表情、看书、伸展、步行、跳跃、拖动、落地、入睡、起身、小舞步和偷吃均已替换为本轮原画。部分行为共享同一套画面，例如左右行走镜像、吃饭与自主用餐。

## 画面与播放

- 使用内置 `image_gen` 制作并筛选 60 张角色关键姿势；原图与生成提示词见 [素材索引](../design/sources/README.md)。所有选用素材均已复制到本机项目。
- 运行时使用 3,219 张透明图片帧，单格 384×384。运动段约 30 张/秒，静止段有意停留；页面刷新调度为 60 Hz，不把调度次数当作新原画帧数。
- 构建阶段用 [RIFE ncnn Vulkan](https://github.com/nihui/rife-ncnn-vulkan) 补齐姿势间的连续画面；运行时直接显示成品图片。没有实时图像生成，也不需要 GPU 视频模型常驻。
- 未参与动作的脸型、发型和脚底固定；步行补入额外四张关键姿势。左右转身围绕实际脚底中心镜像，消除进入步态时的横跳。
- 仅缓存每张图片有内容的区域并保留透明边缘；透明点击掩码使用位图。不会为了减少缓存而降低图片分辨率。
- 同一动作不因重复事件重置起点。按计划刷新时刻采样，避免回调的数毫秒误差让连续原画交替停留 16/50ms。

## 动作节奏

| 活动 | 时长或间隔 | 表现 |
| --- | --- | --- |
| 安静待机 | 持续 | 不追踪视线，不强行眨眼或持续摇摆 |
| 轻微呼吸 | 间隔 45–90 秒，持续 6.5 秒 | 幅度很小 |
| 自主用餐 | 初次 4–7 分钟，其后 5–9 分钟 | 只有少量安静活动自动触发 |
| 自动散步 | 约每 3–5 分钟尝试一次 | 小范围移动，先转身、缓起步、减速收步 |
| 吃饭 | 25.1 秒 | 拿起、停留、咬下、咀嚼、吞咽、放下空手 |
| 惦记零食与偷吃 | 30.75 秒 | 先看一眼、伸手拿取，再接完整用餐 |
| 看书 | 20.65–23.2 秒 | 保留长时间阅读与短暂翻页 |
| 挥手 | 7.1 秒 | 小幅招呼后自然收手 |
| 思考 | 8 秒 | 完成后回到待机，不长时间举手不动 |
| 哼歌、小舞步 | 14.3 秒 | 幅度克制，默认不自动表演 |
| 入睡 | 10 秒后保持睡姿 | 起身另用 5.8 秒完成 |
| 起步、停步转身 | 各 0.6 秒 | 转身时先不移动位置 |

聊天文字可以在长动作期间出现，文字有独立的可读时间。轻点、聊天回复与桌面场景变化不会打断吃饭、看书等长活动；拖动、更换模式、主动选择其他动作等明确操作仍会优先响应。专注、安静、全屏及离开状态抑制自动活动。

## 本机验收

2026-10-23，Windows、本机 RTX 4060、125% 显示缩放、默认 100% 桌宠大小：

- 64 项自动测试通过，覆盖完整动作引用、帧边界、吃饭阶段、有限动作收尾、左右转身脚底、安静节奏、聊天期间动作保持，以及既有记忆与权限行为。
- 全部 40 个片段通过真实 Electron 画布绘制；逐组查看原画和抽样预览，检查轮廓、透明边缘、饭团消失顺序、书页、脚步和睡姿。
- 32 组不同运动片段完成无截图干扰的播放节奏采样，每组约 2.2 秒。最低绘制速率约 29.94 次/秒，最差 p95 帧间隔约 35.1ms；重心回弹等连续变形会以约 60 次/秒重绘。静止段不强制重复绘制。
- 首次素材预载约 12.35 秒。该轮验收时桌宠渲染进程工作集约 1.56 GiB，所有 Electron 进程合计约 2.09 GiB。高分辨率全动作预载仍有明显内存成本，不将短时间采样当作长期资源验收。
- 模拟模型与模拟麦克风的集成检查通过：本地转写、停止聆听释放麦克风、聊天与取消、记忆编辑、设置、喂食、专注、拖动、大小调节和游戏均正常。
- 真实桌面左右行走检查通过：位置单调前进、步态随行程推进、准确到达目标、停下后清除行走相位。此测试使用隔离配置，并固定“用户在场”条件，避免无人操作电脑时的自动入睡干扰。

数据文件：[完整动作与播放节奏结果](../artifacts/animation-qa/report.json)。
