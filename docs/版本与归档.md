## 下载与恢复

每轮 [Release](https://github.com/leaf0329/cuteQ/releases) 保存该轮便携版和安装版。0.4 Release 另有以下整理前材料：

- cuteq-workspace-before-cleanup.7z：整理前的源码、全部有可再分发依据的设计原图、生成提示词、旧图集、构建脚本、测试和说明。
- cuteq-animation-intermediates.7z：制作阶段的 RIFE 黑白底及透明中间帧。
- cuteq-qa-snapshots.7z：各轮动作预览、验收报告、截图和动作对比；剔除测试浏览器用户目录。
- backup-manifest.json：归档逐文件清单与大小，说明排除范围。

归档是整理前状态，其内的本机相对路径和“仍保留旧版”等文字反映当时目录；恢复全部源码和素材时，将工作区与验收归档解压到同一个临时项目根目录。安装包与依赖不包含在上述归档中，分别从各轮 Release 和依赖源取得。社区原始参考图片因授权不明仅本机保存，未放入公开归档。

本地保留当前 0.4 安装包、开发源码、37 段运行视频、仍使用的原画和提示词。旧版、旧预览、重复解包目录、临时归档和中间帧在核实上传后清理。语音模型、node_modules 与制作工具是当前开发/运行依赖，不视为历史备份；个人密钥和共同记忆始终留在应用数据目录。

今后的每轮更新先提交、推送并保存所需交付附件，再清理被替代的本地文件。GitHub 为远端唯一历史留存位置，没有额外异地备份。
