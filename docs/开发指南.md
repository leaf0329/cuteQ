# 开发指南

Windows x64，Node.js 24+。运行 npm ci 安装依赖，npm run speech:prepare 下载本机识别模型，再运行 npm start。运行视频已在仓库中，启动与打包不需要重新生成动画。

## 验证与打包

- npm run check：源码与工具语法检查。
- npm test：后台权限、持久记忆、对话修正、动作时序和窗口物理等契约。
- npm run test:electron：隔离用户目录启动桌宠，验证当前视频与独立后台。
- npm run test:integration：隔离数据、模拟模型及测试音频，验证面板、语音、记忆和设置；不录制真实麦克风，不调用收费模型。
- npm run dist：生成当前便携版和安装版到 artifacts/。

动画专项脚本保留在 scripts/ 中，需要时执行 npm run test:animation、node scripts/walk-qa.cjs 等。长时间测试对应具体动画改动，普通归档整理不重跑整套。用户真实数据不属于测试输入。

安装包未签名；构建日志中的签名步骤不代表具备有效签名证书。GitHub Actions 仅保留手动 Windows 构建，避免整理历史标签时自动重建或覆盖已验收附件；正式快照与安装包按实际轮次人工核实后上传 Releases。

## 素材制作

当前原画与提示词见 [素材索引](../design/sources/README.md)。名称中的 calm-v1、redraw-v2、refine-v3 与 fusion-v4 表示来源批次，这些是当前动作实际依赖的原图，不是旧工作区副本。当前输入关键图保留于 assets/whale/，运行视频在 assets/whale-video/。

- npm run assets:fusion：只重做魔方与行礼，并保留其他当前成品。
- npm run assets:painted（或 assets:build）：由当前原画重建全部关键图、补间和视频；属于制作流程，耗时较长。
- npm run assets:brand：由保留的独立图标原图重建图标；不改角色待机或头像。
- npm run assets:fonts：重建本地字体子集与许可。

补间需要 RIFE ncnn Vulkan 官方 Windows 20221029 工具及 rife-v4.6 模型，位置为 tmp/rife/rife-ncnn-vulkan-20221029-windows/。编码脚本使用 Python imageio_ffmpeg 提供的 FFmpeg；这些只在制作时使用，不是桌宠运行依赖。中间帧写入 artifacts/baked/ 与 assets/whale/painted-*.png，上传归档后可清理。制作工具和模型不纳入 Git。

Codex 外观导出使用已验证的 codex-deepseek-pet/ 包。旧的序列图集、光流、剧情图集构建和历史预览脚本在 [0.4 归档](https://github.com/leaf0329/cuteQ/releases/tag/v0.4.0) 中恢复，不再作为当前构建入口。

## 目录与数据

| 路径 | 用途 |
| --- | --- |
| src/backend/ | 独立角色后台、持久记忆与模型服务 |
| src/main/、src/renderer/ | 原生窗口、行为、面板与透明视频 |
| assets/whale-video/ | 当前运行视频、头像和动作时序 |
| assets/whale/、design/sources/ | 当前制作输入、原图与提示词 |
| assets/fonts/、build/ | 字体及应用图标 |
| resources/speech/ | 本机语音模型，准备命令下载，Git 忽略 |
| artifacts/ | 当前安装包和可清理验收输出，Git 忽略 |
| local-only/ | 未核实可再分发授权的参考原图，Git 忽略 |

角色后台与未来 QQ 的身份/迁移边界见 [使用说明](../使用说明.md) 和 [一期需求](一期需求.md)。当前 QQ 尚未接入；没有自动上传本机记忆的双向同步功能。密钥、role-data/、数据库、录音和 .env 不上传仓库。
