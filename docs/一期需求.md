# cuteQ 第一期

确认日期：2026-10-23。基于 YunYueSama/codex-deepseek-pet 修改，保留原作者署名与许可。

## 已确认

- Windows 本机 Q 版桌宠，复用现有序列帧和窗口互动，不引入 Live2D、3D 或视线功能。
- 手动开启持续语音输入，文字回复；原始音频仅在内存中处理，不保存或上传。
- 本地中文识别，DeepSeek 官方 `deepseek-flash` 负责理解、角色回复和记忆整理；目前官方对应 V4.1-Flash-1017。
- 自言自语可留下记忆，允许不回复；明确对话正常应答。可纠正转写，不把不确定的内容变成确定事实。
- 桌宠与未来 QQ 私聊共用人设、共同经历、对用户的了解和近期话题。
- 第一阶段后台在本机独立进程运行。未来迁移后台与数据到服务器，桌宠与语音识别继续在本机。
- 后续 QQ 实际账号接入、租用和部署服务器不属于本期；本期验证同一后台跨入口读取和修正记忆。

## 本期默认

- 沿用原角色嘴硬、有自尊、贪吃但体贴的人设；支持填写相处约定。
- 麦克风每次启动保持关闭，显式开启后可在面板关闭时继续工作，锁屏、休眠、退出时停止。
- 自言自语模式倾听为主；对话模式每段说完即回应。两种模式均可记忆。
- 本地数据库保存对话和有原话依据的记忆，记忆可编辑、删除；清空聊天与删除长期记忆分开。
- 记忆被修改或删除后，旧的近期上下文不再提供给模型，避免旧信息再次影响回答。
- 网络、识别、模型和存储失败明确提示，不显示为已记住；无 API Key 时不伪造回复。
- 图片观察默认关闭。保留原有手动分享入口。

## 验收

1. 重启后台后，桌面形成的记忆仍可从另一入口取回。
2. 在另一入口修改、删除记忆后，桌面使用新版本，进行中的旧请求不得覆盖修改。
3. 自言自语可以只记忆不回复，明确对话可以回答；模型或网络失败不会写入伪记忆。
4. 本地中文样例可转写；使用模拟音源验证麦克风权限、暂停和文字入口。
5. 桌宠和设置面板正常显示，保留窗口互动，启动即有可见的配置和聆听入口。

真实口音、小声自语、背景视频误收与实际 DeepSeek 质量，需要用户填入密钥后的本机试用验收。
