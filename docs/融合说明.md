# cuteQ 0.4：以我们的统一形象取长补短

参考项目：[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)。用户已明确选择保留我们的外形，借鉴或重绘优秀动作。0.4 正式桌宠的全部运行画面均来自我们此前制作的原画和同形象新画面，不混播另一套脸型、发色与比例不同的角色视频。

## 保留、借鉴与新增

| 内容 | 融合后的做法 |
| --- | --- |
| 形象、头像与原画 | 保留此前的圆脸、明亮蓝眼、钴蓝至青蓝的发梢、女仆装、鲸鱼围裙、鞋袜和尾巴 |
| 饭团、看书、表情、小舞步、散步与睡眠 | 原有全部动作保留，保留长停顿与原定时长 |
| 视频预备播放 | 沿用 0.3 已验证的两个视频元素预备下一段、解码完成再切换的方式；将我们的原画制作成透明视频，避免启动时预载几千张 PNG |
| 专心玩魔方 | 参考 dsh-pet 的持物与把玩设计，按我们的形象新绘四张关键姿势；取出、停留、小幅转动、收回，约 25.2 秒 |
| 女仆行礼 | 参考小幅屈膝与低头节奏，按我们的形象新绘四张关键姿势，约 9.9 秒 |
| 原来的翻本子和认错 | 分别保留，新增魔方与行礼不会替代它们 |
| 休息 | 完成约 10 秒坐下过程后再停留 30 秒，随后用原来的 5.8 秒起身；避免刚坐下就被定时器叫醒 |
| 行为与人格 | 保留低频活动、独立聊天文字、语音转写和共同记忆；新增动作默认手动触发 |

20 个面板互动入口对应 42 个内部动作与过渡状态；部分行为共享画面，不能把 42 个内部名称当作 42 个独立动作。37 个不同视频文件中包含转身、停步等片段。

## 原图和制作方式

新增原图与完整提示词位于 [fusion-v4](../design/sources/fusion-v4/README.md)，使用内置 image_gen，参考图为此前 calm-core 的统一中性姿势。魔方只替换手臂、持物与围裙范围，脸、发丝和腿脚保持原画；行礼使用同一形象的完整姿势。当前关键图和原始生成结果保留于源码；历史候选与补间在 GitHub Release 归档。

延续此前的 RIFE 制作流程，生成小幅动作间的中间画面；当前原画留在本地，中间帧在远端归档后清理。用现有 FFmpeg / libvpx-vp9 将原画按约 30 帧/秒制作成透明视频，保留静止段。编码使用无损模式，颜色仍经过视频的 4:2:0 采样，边缘可能与原 PNG 有轻微差异；没有将视频文件变小等同于画质变好。

源文件位于 `assets/whale-video/`，尺寸 384×384，保持 0.2 的运行帧尺寸。`motion-data.json` 保留动作时长、跳跃阶段、视频对应与来源标记。运行时固定两个视频元素，静态待机暂停视频；透明命中缓存为 96×96。没有常驻视频生成模型，也没有改变真实用户的后台和记忆。

## 验证

- 自动测试检查所有状态只引用我们的画面、原有安静节奏、饭团时长和新增互动。
- 全部 42 个内部状态实际解码并抽样检查透明度，完整播放一次饭团动作。
- 对比实际解码画面，验证魔方停留时脸与头发不变化、睡眠到起身姿势衔接、左右转身到步态的脚底位置、饭团/看书/新动作的中性收尾。
- 检查真实左右散步、透明区域与身体的鼠标命中、镜像与拖动变形。
- 用隔离配置、模拟模型和中文测试音频验证本地语音、聊天、取消、记忆编辑、缩放与面板操作。

本机结果见 `artifacts/0.4-验收结果.md` 与 `artifacts/animation-qa-v04/`；可点选预览为 `artifacts/0.4-动作预览.html`。0.2 原画版和 0.3 素材比较版安装包存于 [GitHub Releases](https://github.com/leaf0329/cuteQ/releases)。

视频播放能减少预载和调度造成的卡顿，不能自动修复每张原画的遮挡或中间画面的美术问题。新增动作已检查关键姿势和抽样衔接；个人使用中的自然程度仍可继续依据实际体验调整。没有实接 QQ、真实收费模型或录制真实麦克风。
