# cuteQ 0.3.0：dsh-pet 素材比较版

试用 dsh-pet 的透明视频动作和两个视频元素的预备播放方式，保留本项目的语音、后台与记忆。

这是 2026-10-23 从本轮已生成的 Windows 便携安装包中恢复的**运行时源码与素材快照**，按更新顺序存入 Git。提交时间为整理时间，不代表原开发时间。包内没有历史构建脚本和锁文件；不宣称能够从此快照独立复现原构建。来源和范围见 [SNAPSHOT.json](SNAPSHOT.json)。
